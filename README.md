# Medical Data Visualizer

A Python data analysis project that visualizes medical examination data using **Pandas**, **NumPy**, **Matplotlib**, and **Seaborn**.

## Features

* Calculate BMI and classify overweight patients.
* Normalize health indicators.
* Create a categorical plot.
* Clean the dataset by removing invalid and extreme values.
* Generate a correlation heatmap.

## Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

## Dataset

[medical_examination.csv](medical_examination.csv)

This project was completed as part of the **FreeCodeCamp Data Analysis with Python** certification.
